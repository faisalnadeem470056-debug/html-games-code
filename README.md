## How to use this HTML game code

1. Open a file in [`games/`](games/) (or the game's page below) and copy the code.
2. Paste it into any text editor and save it as `game.html`.
3. Double-click the file. It opens in Chrome, Safari, Firefox or Edge and works offline.

Every setting (speed, colors, sizes, word lists…) is a constant at the top of the script, so each game is easy to change.

## What you learn from each game

- **Snake:** Grid movement and a setTimeout game loop
- **Tic Tac Toe:** The minimax algorithm (an unbeatable AI)
- **Maze Muncher (Pac-Man Style):** Grid movement, ghost AI targets and game states
- **Flappy Bird:** Gravity, velocity and requestAnimationFrame
- **Tetris-Style Blocks:** Matrix rotation, collision checks and clearing lines
- **2048:** Array logic: sliding and merging rows
- **Memory Card Game:** Fisher–Yates shuffle and 3D card flips in CSS
- **Breakout:** Ball physics and circle–rectangle collision
- **Pong:** A simple AI opponent and bounce angles
- **Dino Runner:** Jump physics and spawning obstacles
- **Space Shooter:** Bullets, spawning enemies and particle explosions
- **Car Racing:** Lane movement and a difficulty curve
- **Sliding Puzzle:** Grid indexes and an always-solvable shuffle
- **Whack-a-Mole:** Timers (setTimeout / setInterval) and DOM events
- **Simon Says:** async / await sequences and the Web Audio API
- **Minesweeper:** Flood fill and counting neighbours
- **Connect Four:** Win detection in four directions and a simple AI
- **Hangman:** String checks and an SVG drawing
- **Rock Paper Scissors:** Random choices and a rules lookup object
- **Number Guessing:** Forms, input validation and binary search
- **Typing Speed Test:** Input events and the WPM formula
